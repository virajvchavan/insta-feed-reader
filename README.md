# InstaReader

A personal Flutter app that reads your Instagram Favorites or Following feed through a hidden WebView,
stores it on the phone, and shows a 24-hour summary, a post feed, and your Instagram messages.

- `CLAUDE.md`: how to work on the project (commands, running on the iPhone, conventions)
- `docs/status.md`: the current spec, what works, and what's next
- `docs/architecture.md`: how the code fits together
- `docs/instagram-notes.md`: verified facts about Instagram's web data
- `PROMPT.md`: the original brief (partly out of date, as `docs/status.md` explains)
